AI College Assistant Chatbot

Project Introduction

AI College Assistant is an AI-based chatbot designed to help students get college-related information easily.

Developed as an academic project for Shambhunath Group of Institutions.

Features

- Student assistance
- College-related information
- AI chatbot interaction
- Simple user interface

Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Ollama
- Llama 3.2

Project Structure

- public/index.html
- server.js
- package.json
- package-lock.json

Installation

1. Install Node.js.
2. Install Ollama.
3. Download the AI model:

"ollama pull llama3.2"

4. Open the project folder in VS Code.
5. Run:

"npm install"

6. Start the server:

"node server.js"

7. Open http://localhost:3000 in your browser.
